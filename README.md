# Portfolio

## Sobre

O projeto é uma aplicação de página única que exibe minhas habilidades, projetos, e informações de contato. Foi construido para servir como vitrine profissional e demonstrar minhas competências em desenvolvimento web moderno.

### Tecnologias principais

- React 18
- TypeScript
- Vite (bundler)
- ESLint + Prettier
- CSS Modules / Tailwind (conforme aplicação)
